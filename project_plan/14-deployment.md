# Этап 14 — Деплой и запуск

**Фаза:** 3 (Интеграция) · **Зависит от:** 13

## Цель
Развернуть сайт на боевом окружении с доменом **roller.tj**, настроить
инфраструктуру, аналитику и финальный SEO.

## Предусловия
- Интеграция завершена (этап 13), сайт работает локально на реальных данных.

## Задачи

### Инфраструктура
- [ ] Выбрать хостинг (открытый вопрос №8). Рекомендация: VPS с
      `docker-compose` (Next.js + FastAPI + PostgreSQL) за Nginx;
      альтернатива — Next.js на Vercel + backend и БД на VPS/managed.
- [ ] Dockerfile для frontend и backend, `docker-compose` для прода.
- [ ] Nginx + HTTPS (Let's Encrypt).
- [ ] Домен **roller.tj** (доступ подтверждён), DNS.
- [ ] Переменные окружения прода — только на сервере, не в репозитории.
- [ ] Бэкапы PostgreSQL.

### Данные и контент
- [ ] Наполнить БД боевым контентом через админку: 6 систем, изображения,
      применения, новости.
- [ ] Загрузить реальные логотипы (`notes/logos/`) и рендеры
      (`notes/Brands products/`), оптимизированные под веб.
- [ ] **Заменить все временные фотографии на реальные объекты** по мере
      поступления съёмки (открытый вопрос №2).
- [ ] Проверить переводы RU / TJ / EN / TR — все поля заполнены.
- [ ] **Портфолио не выкладывать со стоком** — только реальные объекты.

### Финальный SEO и аналитика
- [ ] Проверить `sitemap.xml`, `robots.txt`, метаданные, JSON-LD, `hreflang`.
- [ ] Подключить аналитику (Google Analytics / Яндекс Метрика) — по брифу
      п.17.4 сейчас её нет.
- [ ] Google Search Console, отправка sitemap, проверка индексации.
- [ ] Core Web Vitals на мобильном, проверка скорости.

### Приёмка
- [ ] Прогон по всем страницам и формам на проде, на всех четырёх локалях.
- [ ] Проверить заявку целиком: сохранилась в БД → открылся WhatsApp →
      видна в админке.
- [ ] Проверить отрисовку таджикских **ғ қ ҳ ҷ ӣ ӯ** и турецких **ğ ş İ**
      на реальном контенте.
- [ ] Финальное «ОК» заказчика.
