# Этап 03 — i18n-каркас

**Фаза:** 1 (Frontend) · **Зависит от:** 02 (гейт пройден)

## Цель
Перевести приложение на локализованный роутинг и вынести все строки в файлы
переводов **до** верстки остальных страниц. После этого этапа каждая новая
страница рождается мультиязычной, и переделывать нечего.

> **Почему этот этап здесь, а не в конце.** Локалей четыре. Каждая страница,
> свёрстанная с захардкоженным русским, потом переписывается дважды: перенос
> роутов под `[locale]` и вычистка строк из компонентов. Сейчас готова одна
> страница — это самый дешёвый момент. SEO-часть при этом остаётся в конце
> (этап 08), потому что зависит от того, какие страницы вообще появятся.

## Предусловия
- Дизайн главной утверждён (гейт этапа 02).
- Прочитан `frontend/node_modules/next/dist/docs/01-app/02-guides/internationalization.md`.

## Решения, которые не пересматриваются

| Решение | Значение |
|---|---|
| Библиотека | `next-intl` |
| Локали | `ru`, `tg`, `en`, `tr` (**четыре**) |
| Локаль по умолчанию | `ru` |
| Префикс | `localePrefix: 'always'` — `/ru/…`, `/tg/…`, `/en/…`, `/tr/…` |
| Слаги | **единые латинские** для всех локалей, локализованных путей нет |
| Фолбэк | **отсутствует** — пустое значение выводится пустым |
| Переводы | делает исполнитель; контент к запуску — на всех 4 языках |

Обоснование `always`: `as-needed` создаёт дубли главной (`/` ↔ `/ru`), а SEO —
заявленная цель проекта. Локализованные пути отклонены: слаги брендовые
(`roller`, `stella`, `unopen`, `thermo-60`) и не переводятся ни на один из языков.

## Задачи

### Роутинг
- [ ] Перенести `app/*` под сегмент **`app/[locale]/`**.
- [ ] **`proxy.ts`** в корне `frontend/` — определение локали и редирект.
      ⚠️ В Next.js 16 middleware переименован в **proxy**: `export function proxy(request)`.
- [ ] Корень `/` редиректит на локаль (по `Accept-Language`, дефолт `ru`).
- [ ] `generateStaticParams` для всех локалей в корневом layout.
- [ ] `<html lang>` из текущей локали.
- [ ] `params` асинхронный (`await params`), типы `PageProps<'/[locale]'>` /
      `LayoutProps<'/[locale]'>`.
- [ ] Неизвестная локаль → `notFound()`.

### Переводы
- [ ] `messages/{ru,tg,en,tr}.json` — структура по секциям.
- [ ] Вынести **все** строки из `components/` и `data/home.ts`. Сейчас русский
      текст лежит прямо в объектах (`"ПВХ продукция"`, `"Собственное производство"`).
- [ ] Заполнить все четыре файла (переводы делает исполнитель).
- [ ] Форматирование дат и чисел — через `next-intl` под текущую локаль.

### Переключатель языка
- [ ] Оживить `components/layout/language-switcher.tsx` — сейчас заглушка
      (`// Locale switching logic will be handled in Stage 07`).
- [ ] Переключение сохраняет текущий путь, меняя только префикс локали.
- [ ] Показывает все четыре локали.

### Верстка под мультиязычность
- [ ] Убрать фиксированные ширины под текст: таджикский длиннее русского
      на 10–20%, английский короче — кнопки и заголовки должны переживать оба края.
- [ ] Проверить, что нигде нет текста, зашитого в изображение.
- [ ] **Предзагрузка шрифтов по локали.** Сейчас предзагружаются подмножества
      локали по умолчанию (`latin`, `cyrillic`). Глифы других локалей
      отрисовываются корректно, но догружаются лениво — на TJ и TR возможен
      короткий FOUT. Перечислить все подмножества глобально нельзя: это
      удваивает предзагрузку с 6 до 12 файлов на каждой странице.
      С появлением `[locale]` состав предзагрузки выбирается под локаль.
- [ ] Проверить отрисовку таджикских **ғ қ ҳ ҷ ӣ ӯ** и турецких **ğ ş İ**
      на реальном тексте.

## Результат / артефакты
- `app/[locale]/…`, `proxy.ts`, `messages/{ru,tg,en,tr}.json`, рабочий переключатель.

## Критерии готовности
- Главная открывается на всех четырёх локалях, строк с хардкодом не осталось.
- Переключение языка сохраняет страницу.
- Все специфические глифы TJ и TR отрисовываются фирменным шрифтом.
- `build` / `lint` чистые.

## Заметки
- SEO (`hreflang`, `sitemap`, JSON-LD, канонические URL) — этап 08.
- `next-intl` подключается поверх встроенного паттерна Next 16, а не вместо него:
  роутинг остаётся на `[locale]` + `proxy.ts`.
