## Мультиязычность — JSONB

Все переводимые поля хранятся как **JSONB**:

```python
name = {"ru": "…", "tg": "…", "en": "…", "tr": "…"}
```

Обоснование: полнотекстового поиска по сайту нет (SEO делается статическими
страницами), объём контента мал, а JSON в схеме всё равно появляется из-за
гибких характеристик — один механизм вместо двух. Таблицы переводов дали бы
до 4 строк на сущность и джойн в каждом запросе.

**Фолбэка нет.** Если значение отсутствует — API отдаёт `null`, фронтенд
выводит пусто. Целостность обеспечивается **обязательностью всех четырёх
локалей в админке** (этап 12), а не подстановкой русского.

## Задачи

- [ ] Настроить Alembic (`env.py`, `alembic.ini`, автогенерация).
- [ ] Модели:

| Модель | Поля |
|---|---|
| **Category** | `slug` (`pvc` / `aluminium`), `title` (JSONB), `description` (JSONB), `image`, `order` |
| **Application** | `slug`, `title` (JSONB), `description` (JSONB), `image`, `seo_title` (JSONB), `order` |
| **Product** | `slug`, `name`, `kind` (`system` / `component`), `category_id` (FK), `segment`, `short_description` (JSONB), `description` (JSONB), `logo`, `is_popular`, `order` |
| **ProductApplication** | связь многие-ко-многим `product_id` ↔ `application_id` |
| **ProductSpec** | `product_id` (FK), `name` (JSONB), `value` (JSONB), `order` — **гибкие пары**, не фиксированные колонки |
| **ProductImage** | `product_id` (FK), `url`, `alt` (JSONB), `color`, `order` |
| **ProductColor** | `product_id` (FK), `title` (JSONB), `hex` / `texture`, `order` |
| **Article** | `slug`, `title` (JSONB), `excerpt` (JSONB), `body` (JSONB), `cover`, `published_at`, `is_published` |
| **Project** | `slug`, `title` (JSONB), `city` (JSONB), `description` (JSONB), `images`, `date` |
| **Banner** | `image`, `title` (JSONB), `subtitle` (JSONB), `link`, `order`, `is_active` |
| **ContactInfo** | синглтон: телефоны, WhatsApp, соцсети, адрес, график, карта |
| **Lead** | `name`, `phone`, `city`, `product_type`, `scenario` (`calc` / `quote` / `dealer`), `payload` (JSONB — состав конфигурации), `source`, `created_at` |
| **AdminUser** | `login`, `password_hash`, `created_at` — **2 пользователя**, без ролей |

## Результат / артефакты
- Модели, миграции, сид-данные.

## Критерии готовности
- Миграции применяются на чистой БД без ошибок.
- Сид наполняет каталог шестью брендами и их связями с применениями.
- Все переводимые поля заполнены на четырёх локалях.

## Заметки
- Подтвердить итоговый список брендов (вопрос про **BESTWIN**) **до** сида.
- `Lead.payload` хранит состав конфигурации целиком — тип заявки разбирает
  человек в WhatsApp, поэтому в БД достаточно архива без workflow-полей.
- `Product.kind` позволяет заводить комплектующие (сетки, подоконники,
  кабель-каналы) без миграций, когда у заказчика появится контент.
