## Задачи к доработке

### Токены под `DESIGN.md`
- [x] Шкала радиусов: **8–12px** для карточек и медиа, **8px** для кнопок и полей.
      `--radius-control` (8px) и `--radius-card` (12px); `rounded-full` остался
      только у круглых иконочных кнопок и точек-индикаторов, как разрешает §5.
- [x] Токен контейнера и единая шкала вертикальных отступов секции:
      `--container-page`, `--spacing-gutter`, `--spacing-section` (одна fluid-шкала
      через `clamp`), `--spacing-hero` (74svh). `Container` и `Section` читают их.
- [x] Семантические токены фона: `surface` / `surface-muted` / `surface-inverse`.
      Заведены и **применяются** через проп `Section tone="surface|muted|inverse"`.

### Шрифты — подмножества
- [x] Проверено сборкой: `subsets` в `next/font` управляет **предзагрузкой**,
      а не составом `@font-face`. Блоки эмитятся для всех подмножеств шрифта,
      браузер догружает нужный файл по `unicode-range`. Таджикские
      **ғ қ ҳ ҷ ӣ ӯ** и турецкие **ğ ş İ** отрисовываются Montserrat'ом при
      любом списке `subsets` — в системный шрифт они не выпадают.
- [x] Оставлено `Montserrat: ["latin", "cyrillic"]`, `Chakra Petch: ["latin"]` —
      перечисление всех подмножеств удваивает предзагрузку с 6 до 12 файлов
      на каждой странице, включая русские.
- [x] Зафиксировано в коде: `--font-heading` применяется, но кириллица всегда
      рендерится Montserrat'ом — это ожидаемое поведение, не баг.
- [ ] Предзагрузка по локали — перенесено в **этап 03**, требует `[locale]`.

### Разное

      он давал белый текст на белом фоне. От скролла теперь зависит только тень.
