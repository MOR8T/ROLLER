# Этап 07 — Второстепенные страницы

**Фаза:** 1 (Frontend) · **Зависит от:** 03

## Цель
Оставшиеся контентные страницы: О компании, Портфолио, Новости, Профессионалам,
Контакты.

## Предусловия
- Дизайн утверждён (этап 02), i18n-каркас готов (этап 03).

## Задачи

### О компании `/[locale]/about`
- [ ] История с 2006, 20 лет, миссия и слоган.
- [ ] Новый этап 2025 — ООО «Алюмини Аввалин», алюминиевые профильные системы.
- [ ] Цифры: 400 сотрудников, 10 000 т/год, 1000+ объектов.
- [ ] Собственное производство, монтажные бригады, шоурум.
- [ ] Партнёры: Krauss Maffei, Renolit, Mikrosan, Akdeniz, Dow, Kronos,
      Baerlocher, CNT Conta.
- [ ] Условия гарантии (бриф п.7.5) — юридический текст, переводить аккуратно.

### Портфолио `/[locale]/projects`
- [ ] Сетка объектов: фото, название, город, что установлено, объём.
- [ ] Страница объекта / лайтбокс галереи.
- [ ] **Сток здесь запрещён** — только реальные объекты.
      ⚠️ Раздел 10.2 брифа заполнен **пустым**: ни одного объекта. Контент
      целиком зависит от заказчика (открытый вопрос №3). До его получения
      страница остаётся на моках и **не выкладывается в продакшн**.

### Новости / блог `/[locale]/news` + `/[locale]/news/[slug]`
- [ ] Список статей: обложка, заголовок, дата, анонс.
- [ ] Страница статьи.
- [ ] На моках; управление — через админку (этап 12).

### Профессионалам `/[locale]/professionals`
- [ ] **Новая страница**, которой не было в исходном плане. Обслуживает две из
      четырёх аудиторий: производителей окон/дилеров и архитекторов.
- [ ] Блоки: условия опта и дилерства, комплектующие (профиль, подоконники,
      кабель-каналы, шины, цилиндры, москитный профиль), техническая
      документация, разрезы профиля и узлы, форма «Стать дилером» / «Запросить прайс».
- [ ] **Тёмный тон** — по `DESIGN.md` §3 тёмный фон означает смену аудитории.
- [ ] Ссылка на страницу — из одноимённой секции главной и из шапки.

### Контакты `/[locale]/contacts`
- [ ] Адрес (ул. Мирали Махмадали 25), телефоны, WhatsApp, Telegram, Instagram.
- [ ] График 08:00–18:00.
- [ ] Карта (ссылка из брифа п.15.9).
- [ ] Форма «Заказать звонок» (компонент из этапа 06).

## Результат / артефакты
- Страницы about / projects / news / professionals / contacts.
- Компоненты `ArticleCard`, `ProjectCard`, `MapEmbed`.

## Критерии готовности
- Все пункты навигации ведут на готовые страницы, «висячих» ссылок нет.
- Единый стиль, адаптив, `build` / `lint` чистые.

## Заметки
- FAQ и «Акции» по брифу не требуются.
- Отзывов нет (бриф §11) — раздел не делаем.
- Судьба пункта `/showroom` — открытый вопрос №7. Если он остаётся, страница
  добавляется сюда.
