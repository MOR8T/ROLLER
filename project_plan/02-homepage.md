## Цель
Главная страница, которая за один экран объясняет, чем занимается компания, и
даёт каждой из четырёх аудиторий свою точку входа.

**Перед работой обязательно прочитать `frontend/DESIGN.md`** — композиция,
цвет, форма, изображения и движение описаны там.

  сохранив пропорции бренда (белый / красный / чёрный), и сделать понятным

## Задачи — движение

- [x] Иерархия введена: `Reveal` — только `opacity`, без смещения;
      `RevealGroup` — короткий стаггер со смещением 12px (сдвиг диапазона
      повторяется каждые 4 элемента, чтобы последняя карточка длинной сетки
      не ждала). Всё остальное не анимируется.
- [x] Scroll-reveal переведён на CSS `animation-timeline: view()`. `Reveal` стал
      серверным компонентом без JS; `framer-motion` остался **только** в
      `header-catalog-menu` и `header-mobile-drawer`.
      Оговорка: у scroll-driven анимации нет длительности в секундах — она
      скрабится скроллом, поэтому «0.25s» выражено коротким `animation-range`.
- [x] `prefers-reduced-motion` и отсутствие поддержки `animation-timeline` —
      оба ведут к «контент просто сразу виден» (правила не применяются вовсе).
- [x] Убран count-up у цифр: §8 разрешает движение там, где оно объясняет
      продукт, а бегущее число не объясняет ничего. Заодно секция перестала
      быть клиентской.
