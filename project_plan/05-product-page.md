# Этап 05 — Страница товара

**Фаза:** 1 (Frontend) · **Зависит от:** 04

## Цель
Детальная страница профильной системы: галерея, характеристики, цвета,
применения, преимущества и CTA на подбор/заявку.

## Предусловия
- Каталог и применения готовы (этап 04), товары есть в `data/`.

## Задачи

- [x] Маршрут `app/[locale]/catalog/[category]/[product]/`.
- [x] Блоки страницы:
  - **Галерея** — рендеры из `notes/Brands products`. У ПВХ-брендов это папки
    `1…7` (**цвета ламинации**), внутри `CADR 1…8` (**ракурсы одной конструкции**).
    У алюминия — 4 именованных цвета (антрацит, белый, золотой дуб, коричневый).
  - **Шапка** — название, логотип бренда (или типографика), бейдж сегмента,
    материал, краткое описание.
  - **Таблица характеристик** — из гибких пар `specs`. Верстка не должна
    предполагать фиксированный набор строк.
  - **Цвета** — свотчи. ПВХ ROLLER / STELLA / UNOPEN — общая палитра (по брифу
    «как у Роллера»), **ЭКОЛАЙН — только белый**, алюминий — 4 цвета.
  - **Применения** — где используется, ссылки на лендинги (этап 04).
  - **Преимущества** — текст из брифа.
  - **Разрез профиля** — технический блок, для архитекторов и дилеров.
  - **CTA** — «Подобрать в конфигураторе» и «Заказать звонок» (этап 06).
  - **Другие системы** — соседи по сегменту и по категории.
- [x] Заготовка метаданных (детально — этап 08).
- [x] Адаптив, свайп-галерея на мобильном.
- [x] `next/image` + AVIF/WebP: исходники 3000×3000 PNG, без оптимизации страница
      будет неприлично тяжёлой. Обязательны корректные `sizes`.

## Результат / артефакты
- Страница товара для всех шести систем на моках.
- Компоненты `Gallery`, `SpecTable`, `ColorSwatches`, `RelatedProducts`.

## Критерии готовности
- Открывается для каждой системы, корректна и с логотипом, и без.
- Таблица характеристик работает при любом наборе пар.
- Адаптив, `build` / `lint` чистые.

## Заметки
- Часть контента в брифе дана картинками — текстовые описания дописаны.
- В `notes/` нет папки для **ЭКОЛАЙН** — нужны рендеры (белый) либо запросить
  у заказчика. Страница открывается и без них: галерея и блок разреза
  деградируют до нейтрального плейсхолдера.

## Что выяснилось при разборе исходников

- **Папки `1…7` — не общий код.** Цвет папки у каждого бренда свой: `3` — это
  антрацит у ROLLER, светлый дуб у STELLA и тёмный дуб у UNOPEN. Соответствие
  считано с самих рендеров (цвет непрозрачных пикселей рамы на `CADR 5`) и
  зафиксировано в `frontend/scripts/build-product-renders.py`.
- **Палитра ПВХ — семь цветов, а не шесть**: белый, светлый дуб, золотой дуб,
  орех, тёмный дуб, серый, антрацит. Ранее в `data/catalog.ts` числился
  `mahogany`, которого в рендерах нет.
- **`CADR 1 / 7 / 8` — это разрезы**, а не ракурсы конструкции. Они вынесены в
  технический блок; в галерее остаются `CADR 2…6`.
- **У алюминия разрезов нет вообще** — блок «Разрез профиля» для АЛД-45 и
  ТЕРМО 60 не рендерится, вместо него ближайший кадр (вид с торца) закрывает
  галерею.
- ⚠️ **`UNOPEN/7/CADR 5.png` — антрацитовое окно в папке «белый»**. Файл
  исключён. В той же папке ещё два кадра показывают белую створку в серой
  раме — либо реальный двухцветный вариант, либо та же путаница; нужен ответ
  заказчика.
- ⚠️ **Бриф противоречит сам себе по гарантии.** Карточки товаров: «15 лет на
  цветной и 10 лет на белые»; п.7.5: «15 лет на профиля из ПВХ… гарантия на
  цветные профиля 10 лет» — то есть ровно наоборот. На странице выведены
  только однозначные части п.7.5 (что покрывает / что не входит / когда не
  действует); срок берётся из карточки товара. Требует решения заказчика.
