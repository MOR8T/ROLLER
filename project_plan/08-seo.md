# Этап 08 — SEO и производительность

**Фаза:** 1 (Frontend) · **Зависит от:** 04–07

## Цель
Базовая SEO-оптимизация по всему сайту и приведение Core Web Vitals в норму.

> Роутинг, переводы и переключатель языка сделаны раньше — этап 03. Здесь
> только то, что зависит от готового набора страниц.

## Предусловия
- Все страницы свёрстаны (этапы 04–07) и локализованы (этап 03).

## Задачи

### Метаданные
- [ ] `generateMetadata` для каждой страницы: `title`, `description`, OpenGraph.
- [ ] Локализованные метаданные для всех четырёх локалей.
- [ ] Канонические URL.
- [ ] **`hreflang`** для четырёх языковых версий + `x-default`.
      Префикс локали всегда присутствует (`localePrefix: 'always'`), поэтому
      набор симметричен и дублей главной не возникает.

### Индексация
- [ ] `sitemap.xml` через Next-конвенцию — все страницы × 4 локали.
- [ ] `robots.txt`.
- [ ] Структурированные данные (JSON-LD): `Organization`, `Product`,
      `BreadcrumbList`, `LocalBusiness` (адрес, график, телефон).

### Семантика и контент
- [ ] Один `h1` на страницу, корректная иерархия заголовков.
- [ ] `alt` у всех изображений, локализованный.
- [ ] Ключевые запросы (бриф п.14.2) отрабатываются **лендингами применений**
      (этап 04): «пластиковые окна Душанбе» → `/solutions/windows`,
      «алюминиевые двери Душанбе» → `/solutions/doors`,
      «фасадное остекление» → `/solutions/facade-glazing`.
- [ ] Человекочитаемые слаги, корректные HTTP-статусы, 404 для несуществующих
      локалей и слагов.

### Производительность
- [ ] `next/image` везде, AVIF/WebP, корректные `sizes`.
      Исходники рендеров — 3000×3000 PNG; без этого страницы будут тяжёлыми.
- [ ] Шрифты: `display: swap`, только нужные подмножества и начертания.
- [ ] Проверить вклад `framer-motion` в бандл — после этапа 02 он должен
      остаться только в меню, слайдере и конфигураторе.
- [ ] Core Web Vitals: LCP, CLS, INP.

## Результат / артефакты
- Метаданные, `sitemap.xml`, `robots.txt`, JSON-LD, `hreflang`.

## Критерии готовности
- Lighthouse SEO ≥ 90, критичных a11y-проблем нет.
- `hreflang` корректен для всех четырёх локалей.
- Core Web Vitals в зелёной зоне на мобильном.
- `build` / `lint` чистые.

  сейчас не подключена.
- Google Search Console и проверка индексации — этап 14, после выхода на домен.
